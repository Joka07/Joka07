### Open Source

**[NPUForge](https://github.com/AbdelmonemAwad/os-xgs-npu) — Sophos XGS 116 r1 NPU support**

Contributed an assembly-specific fix for NPU initialization during early boot on the Sophos XGS 116 r1.

- Identified and reproduced the initialization issue on physical hardware.
- Added a narrowly scoped boot-hook fix and automated regression tests.
- Verified successful initialization after reboot, including all nine NPU interfaces.
- Contribution reviewed and merged into the upstream project.

**[View merged PR #1040](https://github.com/AbdelmonemAwad/os-xgs-npu/pull/1040)**
